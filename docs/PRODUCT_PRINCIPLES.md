# School OS product principles

School OSの最上位コンセプト：

「Google集客で『次に何をすればいいか』が分かり、Google経由で何件の面談が生まれたかまで分かる学習塾特化SaaS」

- NEXT ACTION中心。分析だけで終わらず、ACTION → 実行 → 成果計測をつなぐ。
- 「何をするか」と「どうやるか」を、専門知識を要求せず提示する。
- 学習塾の校舎運営に特化し、MEO・Google集客を中心にする。
- SEO・Meta広告・チラシ等へ無制限に広げない。新しい領域は商品方針の確認が必要。
- Google経由の問い合わせ → 面談 → 入塾を追跡する。クリック等の代理指標と実問い合わせを混同しない。
- 自動取得、手動申告、AIによる推定を区別する。未計測・取得失敗を0件や0%にしない。
- 校舎ごとの状況に基づく行動を提示し、架空の成功・成果保証を表示しない。

These principles are the target product direction, not a claim that every current
screen already satisfies it. Known implementation gaps are in ARCHITECTURE.md.
